# 🧠 Deep Learning

This repository contains my **Deep Learning learning journey**, with practical implementations and explanations of fundamental concepts using Python and Jupyter Notebook.

The repository currently focuses on the **Perceptron**, one of the fundamental building blocks of neural networks.

## 📚 Topics Covered

### 1. Perceptron

`1_perceptron.ipynb`

* What is a Perceptron?
* Perceptron architecture
* Weights and bias
* Activation function
* Forward propagation
* Basic Perceptron implementation

### 2. Perceptron Trick

`2_perceptron_trick.ipynb`

* Understanding the Perceptron Trick
* Updating weights
* Updating bias
* Classification using the Perceptron

### 3. Perceptron Loss Function

`3_Perceptron_Loss_Function.ipynb`

* Understanding classification loss
* Perceptron loss function
* Calculating prediction error
* Weight updates based on loss

### 4. Problems with Perceptron

`4_Problem_with_Perceptron.ipynb`

* Limitations of the Perceptron
* Linearly separable vs. non-linearly separable data
* Understanding why a single-layer Perceptron cannot solve certain problems
* Introduction to the need for multi-layer neural networks

## 🚀 How to Use

### Clone the repository

```bash
git clone https://github.com/mohitgoyal1409/deep_learning.git
```

### Navigate to the project

```bash
cd deep_learning
```

### Install required libraries

```bash
pip install numpy matplotlib jupyter
```

### Start Jupyter Notebook

```bash
jupyter notebook
```

Open any `.ipynb` file and run the cells step by step.
